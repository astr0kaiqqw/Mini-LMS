2. Прочитал код входа, сессий и проверок доступа, выписал правила A1–A16 с местом в коде.
3. Проверил каждое правило запросами к API на отдельной БД и снял фактическую матрицу «роль × эндпоинт».
4. Всё закрепил автотестами; пробелы оформил как xfail-тесты, чтобы у каждого задания был проверяемый критерий готовности.
