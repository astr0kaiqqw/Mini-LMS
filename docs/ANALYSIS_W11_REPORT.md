Вероятные вопросы:
- *Зачем xfail-тесты?* Они записывают требование, которое ещё не выполнено. CI остаётся зелёным, а когда пробел закроют, тест начнёт падать и напомнит снять пометку.
- *Почему результат не в `grades`?* Там оценки, которые ставит преподаватель. Результат квиза считает сервер; хранить его в двух местах значит рисковать расхождением. Журнал может показывать лучшую попытку расчётом.
- *Почему квиз открывается только после всех уроков?* Это итоговая проверка по всем темам; счёт идёт по числу завершённых уроков, а не по округлённому проценту.
- *Как вы проверили, что ответы нельзя угадать?* Посчитал по 120 вопросам: правильный вариант не выделяется длиной и равномерно распределён по позициям.
