# Рабочий учебный маршрут Mini LMS

Добавлены [итоговые квизы по всем темам](COURSE_QUIZZES.md): вопросы, таблица правильных ответов для преподавателя/администратора и доступ ученика после всех уроков.

Обновление от 9 ноября 2026. Теперь интерфейс получает данные из PostgreSQL через FastAPI. Переключатель вымышленных ролей убран: роль определяется сервером после входа.

## Что добавлено

- 10 новых курсов: Calculus 1, Linear Algebra, English, Python for Beginners, C++ for Beginners, Philosophy, Cybersecurity, Machine Learning for Beginners, Chinese for Beginners, Databases.
- По 10 текстовых уроков для этих курсов, «Мастерской веба» и «Работы в команде»: описание, объяснение, пример, практика, порядок и длительность. Курс «Данные вокруг нас» с двумя существующими уроками сохранён.
- 36 отдельных тестовых учеников, по 3 на курс, с демонстрационным прогрессом 10%, 50%, 90%. Есть оценки 0 и 92, а также отсутствие оценок. Тестовая активность явно помечена.
- Вход через HttpOnly/SameSite cookie, серверные сессии с истечением через 7 дней. В проекте раньше не было паролей: добавлен единый механизм PBKDF2-SHA256 с 600000 итераций и случайной солью. Старым аккаунтам пароли не назначаются.
- Профиль меняет только имя и описание. Изменение email, роли и чужих записей через этот API запрещено.
- Преподаватель управляет своими курсами/модулями/уроками, ищет учеников, видит подробный прогресс, выставляет и изменяет оценки урока, практики и итог за курс. Шкала — целое число 0–100, сохраняются текущий автор и время изменения.
- Администратор видит всех пользователей и может работать со всеми курсами. Он меняет роль любого пользователя, кроме себя (самоповышение и снятие собственной роли запрещены).

## Запуск на этом компьютере

Из корня проекта, в первом терминале:

```bash
cd /Users/ruslantaikpanov/Desktop/FIS/Mini-LMS
source .venv/bin/activate
# Только если локальный PostgreSQL остановлен:
/opt/homebrew/opt/postgresql@17/bin/pg_ctl -D "$PWD/work/postgres" -l "$PWD/work/postgres.log" -o '-h 127.0.0.1 -p 55434 -k /tmp' start
alembic upgrade head
PYTHONPATH=backend python database/seeds/demo_content.py
PYTHONPATH=backend python database/seeds/learning_demo.py
PYTHONPATH=backend uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Во втором терминале:

```bash
cd /Users/ruslantaikpanov/Desktop/FIS/Mini-LMS/frontend
npm run dev
```

Повторное заполнение не дублирует строки, не сбрасывает выставленные оценки/прогресс и не перезаписывает содержание. У старых уроков дополняются только пустые описание и практика. Если в существующем курсе уже больше десяти полезных уроков, seed сохраняет их все.

## Показ преподавателю

1. Войти как `instructor@demo.example.test`. В «Материалах» выбрать курс и показать 10 уроков, открыть редактор с текстом и практикой.
2. Открыть «Ученики»: 36 строк, выбрать Calculus 1 — останется 3. Показать поиск по имени, 10/50/90%, карточку ученика и отметку тестовых данных.
3. Открыть «Оценки», выбрать Calculus 1 и первого ученика. Выставить 0 за урок или итог курса, затем изменить на 85 и добавить комментарий. При выборе уже оценённой цели форма загружает текущие значения.
4. Выйти, войти первым учеником. У него нет разделов преподавателя/администратора. На странице «Мои оценки» видны только его результаты; «Не выставлена» отличается от нуля.
5. Открыть свой курс и незавершённый текстовый урок, нажать «Завершить урок». Обновить страницу и повторно войти — отметка остаётся. Ученику другого курса доступ закрыт.
6. В DBeaver открыть `mini_lms` на 55434, диаграмму `public` и выполнить `database/queries/learning_demo_checks.sql`: 12 курсов, по 10 уроков и 3 ученика.
7. В коде показать миграции `0003`, `0004`, модели, seed и тесты. Этот объём подготовлен с помощником; личный вклад участника нужно объяснять по фактическому пониманию и изменениям.

## Видео и честные ограничения

Все подготовленные материалы — **текстовые**. Непроверенные видеоссылки не добавлялись. Их завершение происходит только отдельной кнопкой, а процент видео для них отсутствует.

Поддерживается HTML5 `<video>` по прямой ссылке на воспроизводимый ресурс. Преподаватель указывает точную длительность в секундах. Плеер отправляет небольшие непрерывные участки только при воспроизведении; пауза, перемотка и скрытая вкладка не начисляют просмотр. Backend объединяет пересекающиеся участки, поэтому повторный просмотр не увеличивает уникальную длительность. Порог завершения — 90%; общий процент курса считается по завершённым урокам. При замене источника видео его прогресс сбрасывается.

YouTube/другие iframe не поддерживаются: они не подменяются таймером. Недоступный HTML5 источник показывает ошибку. Учёт основан на событиях браузера, не доказывает внимание человека и не защищён от намеренной подделки клиентской телеметрии. Последний запрос прогресса использует keepalive; при потере сети ошибка отображается, несохранённый участок нужно просмотреть повторно.

Регистрация (/register) создаёт аккаунт ученика и сразу открывает сессию; ученик сам записывается на опубликованный курс кнопкой на странице курса, повторная запись не создаёт дубль. Не реализованы сброс пароля и загрузка/отправка решений практики. Практика здесь — текст задания с оценкой преподавателя. Для публичного размещения нужны HTTPS, `COOKIE_SECURE=1`, индивидуальные пароли, ограничение частоты входа и обычная настройка PostgreSQL с паролями.

- Реальные HTTP-запросы через Vite: 13 курсов / 122 урока, вход преподавателя/ученика, 36 зачислений и запреты доступа. Временные прогресс и оценка 77 пережили перезапуск backend и PostgreSQL; временный проверочный курс удалён, исходные демонстрационные показатели сохранены.
- TypeScript/Vite production build проходит. Есть предупреждение deprecation в Starlette/AnyIO.

Воспроизведение тестов — только отдельная чистая БД `mini_lms_test_*`. В этом запуске создана `mini_lms_test_learning`; тестовые изменения откатываются. Если создаёшь новую, сначала используй `createdb` в своём PostgreSQL:

```bash
export DATABASE_URL=postgresql+psycopg://mini_lms@127.0.0.1:55433/mini_lms_test_learning
alembic upgrade head
RUN_DB_TESTS=1 PYTHONPATH=backend pytest backend/tests -q
alembic check
unset DATABASE_URL
```

Откат ниже `0003` удаляет credentials/сессии/прогресс/оценки. Повторный seed намеренно не назначает пароли оставшимся существующим пользователям; для повторения такого разрушительного теста используй чистую одноразовую БД.

Переменную DATABASE_URL не направлять на общую БД при тестах/откатах.
