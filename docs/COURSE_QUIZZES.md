# Итоговые квизы

На странице каждого курса, после списка уроков, находится итоговый квиз.

- 13 текущих курсов, 122 вопроса: один вопрос на каждый урок. Формат — сопоставить тему урока с правильным объяснением; четыре варианта, один правильный. Это вводная проверка понимания тем, не отдельный экзамен на решение задач.
- Ученик получает вопросы и отправляет ответы только после завершения **всех** текущих уроков курса. Проверяется количество завершённых уроков, а не округлённый процент. Также обязательны запись на курс и опубликованный курс.
- Правильные ответы и пояснения не отправляются ученику. После сдачи показываются балл и история собственных попыток. Повторные попытки разрешены, лимит и проходной балл не задавались.
- Преподаватель видит таблицу вопросов и правильных ответов своих/назначенных курсов без прохождения уроков. Администратор — любого курса. Попытки от имени преподавателя/администратора запрещены.
- `quiz_questions`: вопрос, четыре варианта, индекс правильного ответа (0–3), пояснение и уникальная ссылка на урок.
- `quiz_attempts`: ученик, курс, выбранные ответы со снимками вопросов, число правильных ответов, общее число вопросов и время. Результаты квиза сохраняются отдельно от оценок преподавателя.
- После добавления урока квиз недоступен до подготовки вопроса для этого урока; ученику также потребуется завершить новый урок. Seed добавляет недостающие вопросы и сохраняет существующие.

## Подготовка

```bash
source .venv/bin/activate
alembic upgrade head
PYTHONPATH=backend python database/seeds/course_quizzes.py
```

Запускать после заполнения курсов. Для новых уроков без текста сначала заполнить содержание. Интерфейс редактирования вопросов пока не добавлен.

Полная таблица ответов: [QUIZ_ANSWER_TABLE.md](QUIZ_ANSWER_TABLE.md). SQL для преподавателя: `database/queries/course_quizzes.sql`. Markdown — снимок текущих вопросов; актуальные данные находятся в БД и интерфейсе.
