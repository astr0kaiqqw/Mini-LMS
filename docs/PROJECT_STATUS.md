## Что считаем текущим результатом
Новый самостоятельный каркас в astr0kaiqqw/Mini-LMS. Это не копия реализованных функций Yogksai/lms. Из командного репозитория изучены стек и устройство зависимостей; файлы реализации и дизайн не переносились.

Ответственный за координацию — Олжас. Следующая контрольная точка — занятие недели 11; календарную дату нужно подтвердить у преподавателя.

Работает макет с локальными данными; API отдаёт явно обозначенные demo-ответы. PostgreSQL хранит только роли, пользователей и профили. Настоящих сессий, курсов, попыток и оценок пока нет.
