# Как показать БД преподавателю

## Что сделано 9 ноября 2026

Добавлены `courses`, `modules`, `lessons` и миграция `0002`. Вместе с аккаунтами теперь шесть предметных таблиц (плюс служебная `alembic_version`). Курс связан с автором через `users`; курс содержит модули, модуль — уроки.

У курса уникальный `slug`, название и статус `draft`/`published`. Названия не могут быть пустыми. Порядок модулей уникален внутри курса, порядок уроков — внутри модуля; позиции начинаются с 1. Удаление курса удаляет его модули и уроки. Удаление автора существующего курса запрещено. Индекс на авторе и уникальные составные индексы помогают искать связанные записи; ускорение на больших данных пока не измерялось.

Роль автора и право публикации должен проверять backend: внешний ключ проверяет существование пользователя, но не его роль. API и сайт пока используют demo-данные. Пароли, сессии, запись на курс, прогресс, тесты и оценки этой миграцией не добавлены.

## Где показать

Открой проект в VS Code. Покажи:

1. `backend/app/models.py` — описание трёх новых таблиц.
2. `database/migrations/versions/0002_course_content.py` — создание таблиц и обратная миграция.
3. `database/seeds/demo_content.py` — курс, модуль и два урока; повторный запуск не создаёт дубликаты и не перезаписывает записи.
4. `database/queries/course_overview.sql` — запрос, соединяющий курс, автора, модуль и уроки.
5. Терминал с реальными таблицами, результатом запроса и тестами.

В браузере пока показывается макет. Сохранение содержания доказывай через PostgreSQL.

## Готовое окружение этого запуска

Для проверки создан отдельный временный PostgreSQL 17 в `/tmp/mini_lms_course_pg`, порт `55433`, БД `mini_lms_test_content`, пользователь `mini_lms`. Только локальный доступ; это одноразовый кластер без пароля с вымышленными данными. Он не является обычной БД из Docker Compose. Каталог `/tmp` может очищаться после перезагрузки.

В терминале из корня проекта:

```bash
cd /Users/ruslantaikpanov/Desktop/FIS/Mini-LMS
source .venv/bin/activate
export DATABASE_URL=postgresql+psycopg://mini_lms@127.0.0.1:55433/mini_lms_test_content
alembic current
psql -h 127.0.0.1 -p 55433 -U mini_lms -d mini_lms_test_content -c '\dt'
psql -h 127.0.0.1 -p 55433 -U mini_lms -d mini_lms_test_content -f database/queries/course_overview.sql
RUN_DB_TESTS=1 PYTHONPATH=backend pytest backend/tests -q
```

В DBeaver или pgAdmin можно подключиться к тем же host/port/database/user и открыть таблицы. Пароль оставь пустым. Для структуры и ограничений в psql используй `\d courses`, `\d modules`, `\d lessons`.

Если временный кластер существует, но остановлен:

```bash
/opt/homebrew/opt/postgresql@17/bin/pg_ctl -D /tmp/mini_lms_course_pg -l /tmp/mini_lms_course_pg.log -o '-h 127.0.0.1 -p 55433 -k /tmp' start
```

Для постоянного запуска используй Docker Compose по README, затем `alembic upgrade head` и `PYTHONPATH=backend python database/seeds/demo_content.py`. Там адрес подключения берётся из `.env`, порт по умолчанию 55432. Не копируй тестовый DATABASE_URL в общее окружение.

## Что сказать простыми словами

«Я добавил хранение учебного содержания: курс состоит из модулей, а модуль — из уроков. Связи защищены внешними ключами. Нельзя добавить урок к несуществующему модулю или два урока с одинаковым порядковым номером в одном модуле. Схему меняю через Alembic, поэтому её можно воспроизвести. Добавлены демонстрационные данные и проверки на PostgreSQL. Подключение экранов к этим таблицам — следующий этап команды».

Разбери миграцию и тесты перед защитой: код подготовлен с помощником, это не доказательство самостоятельного написания.

## Фактическая проверка

9 ноября 2026: PostgreSQL 17, Python 3.14, зависимости из `backend/requirements.txt` в локальном `.venv` (полный lock-файл не проверялся).

- С нуля применены `0001` и `0002`.
- `alembic check`: `No new upgrade operations detected`.
- `RUN_DB_TESTS=1 PYTHONPATH=backend pytest backend/tests -q`: **28 passed**, без пропусков; одно предупреждение deprecation в Starlette/AnyIO.
- `0002` откачена до `0001`, затем снова применена.
- Seed содержания выполнен дважды; запрос показывает один курс, один модуль, два урока.
- Тесты проверяют ограничения, отсутствие дублей, каскадное удаление, защиту автора и независимый порядок у разных родителей. Изменения тестов откатываются транзакцией.

Откат миграции удаляет содержание — выполнять только в одноразовой тестовой БД.
